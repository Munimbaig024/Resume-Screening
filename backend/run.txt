============================================================
  RESUME CHECKER BACKEND — Setup & Run
  Location: f:\Rafay\resume_checker\backend\
============================================================

STEP 1 — Create & activate virtual environment:
-------------------------------------------------
  python -m venv venv
  venv\Scripts\activate

STEP 2 — Install dependencies:
--------------------------------
  pip install -r requirements.txt

STEP 3 — Fill in your .env:
-----------------------------
  MONGO_URI=mongodb://localhost:27017/resume_checker
  GROQ_API_KEY=<get free key at console.groq.com>
  JWT_SECRET_KEY=<any 32+ char random string>
  ENCRYPTION_KEY=<run step 4 to generate this>

STEP 4 — Generate encryption key:
-----------------------------------
  python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
  (paste output into ENCRYPTION_KEY in .env)

STEP 5 — Setup MongoDB (run ONCE):
------------------------------------
  Make sure MongoDB is running first:
    mongod --dbpath C:\data\db

  Then run:
    python setup_db.py

STEP 6 — Start the server:
----------------------------
  python app.py
  Open -> http://localhost:5000

============================================================
  QUICK ONE-LINER (after venv + .env configured):
============================================================
  python setup_db.py && python app.py

============================================================
  API ENDPOINTS:
============================================================

Auth:
  POST /api/auth/register  -- { name, email, password }
  POST /api/auth/login     -- { email, password }
  POST /api/auth/logout    -- clears cookies
  POST /api/auth/refresh   -- rotates access token
  GET  /api/auth/me        -- returns current user

Resume:
  POST /api/resume/analyze -- multipart: resume(file), industry, job_description?
  GET  /api/resume/history -- past reports (login required)

AI Chat:
  POST   /api/chat         -- { message } -> { reply }
  GET    /api/chat         -- chat history
  DELETE /api/chat         -- clear history

Health:
  GET /api/health          -- { status: "ok" }
